Engineering Specification and Actionable Implementation Backlog for Refactoring the Open-Tennis Framework into a Modernized Pickleball Video Analytics Platform
The open-tennis framework provides a foundational computer vision architecture designed to analyze tennis matches using object detection, court boundary line extraction, and scoreboard parsing. However, legacy systems designed around classical tennis dynamics struggle when adapted to pickleball due to significant differences in court geometry, faster ball speeds, smaller ball profiles, and unique scoring structures.2
This specification provides a comprehensive, self-contained guide for Google Antigravity to refactor, modernize, and adapt the open-tennis repository into a high-precision pickleball analytics platform.1
Architectural Assessment of the Open-Tennis Legacy Framework and Transition Strategy
The legacy open-tennis system depends on a rigid framework optimized for standard broadcast tennis matches. Re-engineering this codebase for pickleball requires replacing outdated components with modern, high-precision computer vision techniques.5
Legacy Codebase Analysis
The original open-tennis repository is structured as a pipeline that runs single-camera video inference to extract court edges and detect scoreboards. The legacy architecture consists of:
* An orchestrator (app.py) that handles configuration parsing and frame iteration.
* A scoreboard localization module using YOLOv5 for region of interest bounding boxes.
* An optical character recognition (OCR) sub-system relying on TesserOCR or CRNN to extract player names and scores.
* A classical Hough Transform line-detection model to localize court boundaries.

Limitations of Classical CV and YOLOv5 in Pickleball Environments
Adapting this legacy pipeline directly to pickleball exposes several technical limitations 2:
1. Vulnerability of Hough Transforms to Multi-Line Noise: Classical line detection using Hough transforms depends on high-contrast white pixels and manual parameter tuning. Pickleball courts feature interior markings—specifically the non-volley zone (NVZ) or "kitchen" lines and centerlines—that lie close to each other.3 This proximity often causes Hough models to snap incorrectly to the net or adjacent interior lines rather than the outer court boundaries.5
2. Inadequate Resolution for Small Object Tracking: The legacy YOLOv5 detector operates at a default resolution of    pixels.1 While sufficient for a bright yellow tennis ball, this resolution is too low to reliably detect a standard pickleball.5 A pickleball is smaller (approximately    in diameter), has multiple perforated holes that soften its visual edge, and moves at speeds up to    (  ), causing severe motion blur.5 Running inference at    results in a low ball-detection rate of around 60%, whereas upgrading the inference resolution to    increases detection accuracy to nearly 100%.5
3. Inefficient Multi-Stage Inference: The legacy scoreboard pipeline runs separate deep networks for localization and text recognition, adding overhead that limits real-time performance on edge hardware.1
4. Lack of Spatial and Kinematic Tracking: The open-tennis framework only identifies players and courts visually; it lacks the coordinate mapping needed to calculate physical metrics like ball velocity, player speed, and run distances.1

During doubles play, the system tracks and reports three numbers: the serving team's score, the receiving team's score, and the active server number (either 1 or 2).4 A side-out occurs when the serving team loses a rally on their second server's turn, which transfers service to the opposing team.4

import numpy as np
import cv2

class GeometrySolver:
   def __init__(self, canonical_points=None):
       # 12 canonical floor positions for a 20x44 ft pickleball court (in feet)
       self.canonical_points = canonical_points if canonical_points is not None else np.array([0.0, 44.0],   # K0: Left Opponent Baseline
           [10.0, 44.0],  # K1: Center Opponent Baseline
           [20.0, 44.0],  # K2: Right Opponent Baseline
           [0.0, 29.0],   # K3: Left Opponent NVZ Line
           [10.0, 29.0],  # K4: Center Opponent NVZ Line
           [20.0, 29.0],  # K5: Right Opponent NVZ Line
           [0.0, 15.0],   # K6: Left Server NVZ Line
           [10.0, 15.0],  # K7: Center Server NVZ Line
           [20.0, 15.0],  # K8: Right Server NVZ Line
           [0.0, 0.0],    # K9: Left Server Baseline
           [10.0, 0.0],   # K10: Center Server Baseline
           [20.0, 0.0]    # K11: Right Server Baseline
       ], dtype=np.float32)
       self.H = None
       self.H_inv = None

   def fit_homography(self, detected_keypoints):
       """
       Calculates the homography matrix using 12 detected points and canonical points.
       detected_keypoints: numpy array of shape (12, 2)
       """
       pts_src = np.array(detected_keypoints, dtype=np.float32)
       self.H, status = cv2.findHomography(pts_src, self.canonical_points, cv2.RANSAC, 5.0)
       if self.H is None:
           raise ValueError("Homography fitting failed; invalid keypoint distribution.")
       self.H_inv = np.linalg.inv(self.H)
       return self.H

   def pixel_to_court(self, pixel_coord):
       """
       Converts pixel coordinates (x, y) to physical court coordinates (x', y') in feet.
       """
       if self.H is None:
           raise ValueError("Homography solver must be initialized first.")
       pt = np.array([pixel_coord, pixel_coord, 1.0], dtype=np.float32).reshape(3, 1)
       projected = np.dot(self.H, pt)
       w = projected
       return np.array([projected / w, projected / w], dtype=np.float32)

   def court_to_pixel(self, court_coord):
       """
       Converts physical coordinates (x', y') in feet to pixel coordinates (x, y).
       """
       if self.H_inv is None:
           raise ValueError("Homography solver must be initialized first.")
       pt = np.array([court_coord, court_coord, 1.0], dtype=np.float32).reshape(3, 1)
       projected = np.dot(self.H_inv, pt)
       w = projected
       return np.array([projected / w, projected / w], dtype=np.float32)

   def calculate_velocity_and_speed(self, coord_t1, coord_t2, fps):
       """
       Calculates the physical speed of the ball in mph.
       """
       dist_ft = np.linalg.norm(coord_t2 - coord_t1)
       time_sec = 1.0 / fps
       vel_fps = dist_ft / time_sec
       # Convert feet/second to miles/hour
       speed_mph = vel_fps * 0.681818
       return vel_fps, speed_mph

   def is_within_court_polygon(self, physical_coord, padding=3.0):
       """
       Verifies if a physical coordinate is within the boundaries of the court (plus padding).
       """
       x, y = physical_coord, physical_coord
       return (-padding <= x <= 20.0 + padding) and (-padding <= y <= 44.0 + padding)

import numpy as np

class PlayerTracker:
   def __init__(self, geometry_solver, min_track_length=15):
       self.geometry_solver = geometry_solver
       self.min_track_length = min_track_length
       self.active_tracks = {}

   def update_player_tracks(self, frame_id, detected_persons):
       """
       Filters out spectator noise and tracks active players on the court.
       detected_persons: list of bounding boxes [x1, y1, x2, y2, track_id]
       """
       updated_tracks = {}
       for box in detected_persons:
           x1, y1, x2, y2, track_id = box
           # Base coordinate (center bottom of player bounding box)
           center_x = (x1 + x2) / 2.0
           center_y = y2
           
           # Map bottom-center pixels to the physical court floor
           physical_pos = self.geometry_solver.pixel_to_court((center_x, center_y))
           
           # Filter: Drop track if player is outside the court boundary (including padding)
           if not self.geometry_solver.is_within_court_polygon(physical_pos, padding=5.0):
               continue
               
           if track_id not in self.active_tracks:
               self.active_tracks[track_id] = {
                   "history":,
                   "physical_history":,
                   "frames":
               }
               
           self.active_tracks[track_id]["history"].append([x1, y1, x2, y2])
           self.active_tracks[track_id]["physical_history"].append(physical_pos)
           self.active_tracks[track_id]["frames"].append(frame_id)
           updated_tracks[track_id] = self.active_tracks[track_id]
           
       # Clean up short tracks to reduce noise from passing spectators
       cleaned_tracks = {}
       for track_id, data in updated_tracks.items():
           if len(data["frames"]) >= self.min_track_length:
               cleaned_tracks[track_id] = data
               
       return cleaned_tracks

import cv2
import numpy as np

class FrameDifferenceDetector:
   def __init__(self, threshold_value=25):
       self.prev_frame = None
       self.threshold_value = threshold_value

   def detect_motion(self, frame_image):
       """
       Performs frame subtraction to isolate moving objects when YOLO fails.
       """
       gray = cv2.cvtColor(frame_image, cv2.COLOR_BGR2GRAY)
       gray = cv2.GaussianBlur(gray, (5, 5), 0)
       
       if self.prev_frame is None:
           self.prev_frame = gray
           return None
           
       frame_delta = cv2.absdiff(self.prev_frame, gray)
       thresh = cv2.threshold(frame_delta, self.threshold_value, 255, cv2.THRESH_BINARY)
       thresh = cv2.dilate(thresh, None, iterations=2)
       
       contours, _ = cv2.findContours(thresh.copy(), cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
       self.prev_frame = gray
       
       # Identify the smallest contour matching a pickleball's size profile
       for contour in contours:
           if cv2.contourArea(contour) < 10 or cv2.contourArea(contour) > 500:
               continue
           (x, y, w, h) = cv2.boundingRect(contour)
           # Return the center point of the detected motion
           return (x + w / 2.0, y + h / 2.0)
           
       return None

       self.max_velocity_fps = max_velocity_fps
       self.fps = fps
       self.max_step_distance = max_velocity_fps * (1.0 / fps)
       self.trajectory = # Holds physical coords: (x', y', frame_id)
       self.motion_detector = FrameDifferenceDetector()

   def process_frame(self, frame_id, frame_image, yolo_ball_centroid):
       """
       Validates and links ball detections across frames.
       """
       physical_candidate = None
       
       # Map YOLO detections to physical court coordinates
       if yolo_ball_centroid is not None:
           physical_candidate = self.geometry_solver.pixel_to_court(yolo_ball_centroid)
           
       # Physical Constraint Check: Filter out improbable position jumps
       if physical_candidate is not None and len(self.trajectory) > 0:
           last_pos = np.array(self.trajectory[-1][:2], dtype=np.float32)
           dist_moved = np.linalg.norm(physical_candidate - last_pos)
           
           if dist_moved > self.max_step_distance:
               # Discard detection if it exceeds physical movement speed limits
               physical_candidate = None

       # Fallback Check: Trigger motion-differencing if YOLO fails
       if physical_candidate is None and frame_image is not None and len(self.trajectory) > 0:
           fallback_pixel = self.motion_detector.detect_motion(frame_image)
           if fallback_pixel is not None:
               fallback_physical = self.geometry_solver.pixel_to_court(fallback_pixel)
               last_pos = np.array(self.trajectory[-1][:2], dtype=np.float32)
               dist_moved = np.linalg.norm(fallback_physical - last_pos)
               if dist_moved <= self.max_step_distance:
                   physical_candidate = fallback_physical

       if physical_candidate is not None:
           self.trajectory.append((physical_candidate, physical_candidate, frame_id))
           return physical_candidate
           
       return None

   def interpolate_gaps(self, max_gap_frames=5):
       """
       Interpolates short tracking gaps using cubic spline interpolation.
       """
       if len(self.trajectory) < 3:
           return self.trajectory
           
       interpolated =
       for i in range(len(self.trajectory) - 1):
           curr_pt = self.trajectory[i]
           next_pt = self.trajectory[i+1]
           gap = next_pt - curr_pt
           
           interpolated.append(curr_pt)
           if 1 < gap <= max_gap_frames:
               for step in range(1, gap):
                   alpha = step / float(gap)
                   interp_x = (1 - alpha) * curr_pt + alpha * next_pt
                   interp_y = (1 - alpha) * curr_pt + alpha * next_pt
                   interp_frame = curr_pt + step
                   interpolated.append((interp_x, interp_y, interp_frame))
                   
       interpolated.append(self.trajectory[-1])
       self.trajectory = interpolated
       return self.trajectory

           # Server must be on the left side of the court (x < 10.0 ft)
           return server_x_coord < 10.0

   def register_point(self, winning_team):
       """
       Updates the scoring state machine.
       """
       # In traditional scoring, only the serving team can win points
       if winning_team == "SERVER":
           self.current_state["server_score"] += 1
       else:
           # Side-out logic
           if self.current_state["server_num"] == 1:
               self.current_state["server_num"] = 2
           else:
               # Turn service over to the receivers
               self.current_state["server_num"] = 1
               temp = self.current_state["server_score"]
               self.current_state["server_score"] = self.current_state["receiver_score"]
               self.current_state["receiver_score"] = temp
               
       return self.current_state

import requests
import base64
import logging

class DUPRClient:
   def __init__(self, api_url, client_key, client_secret, sandbox_mode=False):
       self.api_url = api_url.rstrip('/')
       self.client_key = client_key
       self.client_secret = client_secret
       self.sandbox = sandbox_mode
       self.token = None
       self.logger = logging.getLogger("DUPR_Client")

   def authenticate(self):
       """
       Exchanges client credentials for a stateless JWT token.
       """
       auth_str = f"{self.client_key}:{self.client_secret}"
       encoded_auth = base64.b64encode(auth_str.encode('utf-8')).decode('utf-8')
       headers = {
           "x-authorization": f"Basic {encoded_auth}",
           "Content-Type": "application/json"
       }
       
       endpoint = f"{self.api_url}/auth/v1.0/token"
       try:
           response = requests.post(endpoint, headers=headers, timeout=10)
           if response.status_code == 200:
               self.token = response.json().get("token")
               return True
           else:
               self.logger.error(f"Authentication failed: {response.status_code} - {response.text}")
               return False
       except Exception as e:
           self.logger.error(f"Error during DUPR authentication: {str(e)}")
           return False

   def upload_match_result(self, payload):
       """
       Posts verified match results to DUPR.
       """
       if self.token is None:
           if not self.authenticate():
               raise ConnectionError("Authentication required to post match results.")
               
       headers = {
           "Authorization": f"Bearer {self.token}",
           "Content-Type": "application/json"
       }
       
       endpoint = f"{self.api_url}/v1.0/match"
       try:
           response = requests.post(endpoint, json=payload, headers=headers, timeout=10)
           if response.status_code in :
               return {"status": "SUCCESS", "data": response.json()}
           elif response.status_code == 429:
               return {"status": "RATE_LIMITED"}
           else:
               return {"status": "FAILED", "error": response.text}
       except Exception as e:
           return {"status": "ERROR", "exception": str(e)}
